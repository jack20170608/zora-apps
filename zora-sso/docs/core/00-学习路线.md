# SSO 学习路线

`core` 面向第一次系统学习认证与单点登录的开发者。这里先建立概念，再理解协议，最后讨论安全；项目落地请转到 [实战设计](../design/README.md)。

## 学习顺序

| 阶段 | 文档 | 学完后应能回答 |
|---|---|---|
| 1 | [认证基础](01-认证基础.md) | 认证、授权、Cookie 和 Session 分别是什么？ |
| 2 | [OAuth 2.0](02-OAuth-2.0-授权.md) | OAuth 解决什么问题，为什么它本身不是登录协议？ |
| 3 | [OpenID Connect](03-OpenID-Connect-身份认证.md) | OIDC 如何在 OAuth 之上表达用户身份？ |
| 4 | [浏览器 SSO](04-浏览器SSO与会话.md) | 用户为什么只登录一次，多个应用如何建立各自会话？ |
| 5 | [Token 与校验](05-Token与校验.md) | ID Token、Access Token、Refresh Token 如何正确使用？ |
| 6 | [安全基线](06-威胁模型与安全基线.md) | state、nonce、PKCE 各自防御什么，哪些校验不能省略？ |
| 7 | [选型与进阶](07-协议选型与进阶.md) | 应选择 OIDC、SAML 还是自建方案？下一步学什么？ |

## 建议方法

每章按“问题 -> 模型 -> 流程 -> 检查点”阅读。先能用自己的话画出流程，再看具体产品配置；不要从复制 Keycloak 配置或 JWT 代码开始。

完成第 1 至 4 章后，可以阅读当前 [本地 POC 架构](../design/01-ARCHITECTURE-本地认证POC架构.md)。完成第 5、6 章后，再阅读 [生产目标架构](../design/04-ARCHITECTURE-生产级OIDC目标架构.md)。

## 范围说明

- 本教程重点是浏览器应用的 SSO。
- OAuth 2.0 的现代推荐主线是 Authorization Code + PKCE。
- Implicit Grant 和 Resource Owner Password Credentials 仅作为历史概念认识，不作为实现方案。
- `zora-sso` 当前 POC 是教学和流程验证代码，不代表标准 OAuth 2.0/OIDC 实现。
