# zora-sso 文档

文档分为两条互补路线，阅读时不要混淆“协议知识”“当前实现”和“目标方案”。

## Core：从零学习 SSO

[core](core/00-学习路线.md) 从认证基础开始，逐步讲解 OAuth 2.0、OIDC、浏览器 SSO、Token 校验和安全基线。这里解释“为什么”，不绑定当前项目实现。

适合：

- 第一次系统学习 SSO；
- 需要补齐 OAuth/OIDC 基础；
- 参与实现前统一术语与安全认知。

## Design：从项目实战落地

[design](design/README.md) 以 `zora-sso` 为对象，分成两条轨道：

- **当前轨道**：准确描述已经实现的本地认证 POC、调用流程与风险边界。
- **目标轨道**：设计基于 Keycloak/OIDC 的生产架构、客户端接入、迁移和运维方案。

实战文档中的状态标记：

| 标记 | 含义 |
|---|---|
| 已实现 | 当前代码和测试已经覆盖 |
| 目标设计 | 尚未实现，不应被当作现有能力 |
| 禁止生产 | 仅用于本地验证，不允许通过配置绕过风险边界 |
