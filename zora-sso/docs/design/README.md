## 决策原则

1. 当前 POC 只验证中央会话和一次性身份交接，不扩建成 OAuth/OIDC Provider。
2. 生产环境使用成熟 Provider；`zora-sso` 聚焦统一客户端接入和本地身份映射。
3. 默认拒绝：配置、协议或身份无法验证时，不创建降级身份。
4. 每项目标能力必须在实现、测试和运维手册完成后，才能把状态改为“已实现”。
